# Cinematic Scroll Portfolio

A React and WebGL portfolio built around a single-canvas architecture, scroll-led motion, and a deliberate black-and-white visual language.

## Prerequisites

- Node.js 20.19+ or 22.12+
- npm 10+

## Commands

```bash
npm install
npm run dev
npm run lint
npm run format:check
npm run build
```

## Project Docs

- `AGENTS.md` contains non-negotiable implementation constraints.
- `docs/ARCHITECTURE.md` describes the durable system design.
- `docs/PROJECT_CONTEXT.md` records the current build state.
- `docs/DECISIONS.md` is the append-only decision log.
- `docs/TASKS.md` is the active implementation queue.
